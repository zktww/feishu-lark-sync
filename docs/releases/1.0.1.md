# Feishu Lark Sync 1.0.1

修复首版发布的源码与附件不一致问题，并完善跨平台发布校验。

- **版本一致性**：插件名称、作者、源码标签与 Release 附件保持一致，不再覆盖已发布的 1.0.0。
- **Windows CI**：统一 LF 换行，修复检出后的格式检查失败。
- **发布校验**：拒绝旧标签、版本不一致、错误提交和构建期间被修改的源码。
- **构建来源证明**：通过 GitHub Actions 构建并为安装文件和 ZIP 生成可验证的 provenance attestations。

无同步逻辑、权限范围或状态格式变化。现有同步源、授权和本地数据无需迁移。

## 安装与升级

下载本 Release 的 `main.js`、`manifest.json`、`styles.css`，放入 `<Vault>/.obsidian/plugins/feishu-lark-sync/`。升级前备份知识库，仅替换上述三个文件，不要覆盖或删除 `data*.json` 和笔记备份；然后重新启用插件。

需要 Obsidian 桌面端 1.11.4+、独立安装的官方 `lark-cli` 及用户授权。功能边界和使用方式见 [简体中文指南](https://github.com/zktww/feishu-lark-sync/blob/1.0.1/README.zh-CN.md)。

## English

This patch aligns the release tag, source metadata and downloadable assets; fixes Windows checkout line endings; and adds exact-source release validation plus GitHub build-provenance attestations. Synchronization behavior, permissions and the data schema are unchanged.

Upgrade by replacing only `main.js`, `manifest.json` and `styles.css`. Preserve settings and backups. See the [English guide](https://github.com/zktww/feishu-lark-sync/blob/1.0.1/README.md).
